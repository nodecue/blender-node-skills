# Changelog

All notable changes to this repository. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versions match `version` in `.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json`, and `.codex-plugin/plugin.json`.

Releases before 0.7.0 were not tagged; their dates are when the version number changed. Every pull request that changes user-visible behavior, the skill's guidance, or the package adds a line under **Unreleased**.

## Unreleased

### Added

- Codex plugin packaging: `.codex-plugin/plugin.json` points at the shared `skills/` directory and a portable `blender-mcp` stdio entry in `.mcp.json`. Local Codex acceptance only; not a tagged plugin release.
- `scripts/layout_graph.py`: deterministic, scoped graph layout. `check` reports node and frame overlap without changing anything; `apply` moves only nodes the caller authorized.
- `scripts/find_nodes.py`: deterministic node routing over `references/nodes.tsv`. Supports several intents per call (`queries`), IDF-weighted ranking with a whole-name bonus, plural normalization, reviewed aliases, and an empty-result hint.
- `scripts/verify_result.py`: evaluates a group on its object or on temporary sample hosts and reports attribute ranges, constants, all-zero and missing attributes, and whether the group survives a save.
- Public test suite under `tests/` (skill entrypoint, references, plugin package, runtime-script contracts, `nodes.tsv`, `find_nodes`) and a Blender-side runtime check in `tests/golden/`.
- `tools/eval_find_nodes.py` with the intent set in `tests/fixtures/find_nodes_cases.json`.
- Pull-request quality gates in `.github/workflows/quality.yml`: the test suite and `tools/gen_nodes_tsv.py --check`.
- Pull request template.

### Changed

- `read_graph.py` and `probe_node.py` return compact output by default; `detail: "full"` keeps the raw form. The `read_graph` summary carries the group interface, and unknown parameters are rejected.
- Blender-side scripts no longer print their result as well as returning it through the runpy channel, which doubled every payload in the host's context. CLI output is compact JSON.
- `SKILL.md` is shorter: copyable script invocations, `find_nodes` only for uncertain nodes with one intent per query, value verification in the build loop, and a note that a group with zero users is not saved.
- README files document Blender Lab MCP setup, a read-only connection smoke prompt, and the evidence behind the Codex plugin. The pre-v0.7 comparison screenshots are gone.
- `CONTRIBUTING.md` covers local setup, the checks to run, and regenerating `nodes.tsv`.

### Removed

- Internal agent guidance and project records (`AGENTS.md`, `docs/CURRENT.md`, `docs/HANDOFF.md`, `docs/PRODUCT.md`, and notes under `docs/`) from the public tree.

## 0.7.0 — 2026-09-11

### Changed

- Replaced the category rules/patterns package with a nine-file runtime: one entrypoint (`SKILL.md`), four conditional references (`nodes.tsv`, `versions.md`, `reuse.md`, `diagnostics.md`), and four Blender scripts (`read_graph.py`, `probe_node.py`, `inspect_assets.py`, `capture.py`).
- Added a reproducible 368-node routing index (`references/nodes.tsv`, generated by `tools/gen_nodes_tsv.py` from `docs/node-dumps/`), live graph and node inspection, bounded asset inspection, and opt-in node-editor capture.
- Added project-local memory guidance, script invocation instructions, and named-attribute evaluation-context guidance.

### Fixed

- Removed unsupported field-capability assumptions and fixed geometry trunk/dependency classification.

### Removed

- `rules/`, `patterns/`, and `evals/` from the skill.

Runtime regression checks passed. Full host behavioral acceptance was still pending, and no new connection adapter was included.

## 0.6.0 — 2026-07-18

Includes the follow-up changes through 2026-07-31.

### Added

- Blender 5.2 support: 36 new node entries across 15 rule files (the 5.2 release notes list 26; live enumeration found 10 more), each with `Version` and `Evidence` metadata. New version-awareness rules gate `5.2+` nodes on older Blenders and resolve sockets through live readback where identifiers changed. The mental model gained the 5.2 list and geometry-bundle data shapes.
- Blender 4.5 LTS coverage from a live audit (350 node types created on 4.5.12; 45 shared nodes diffed against 5.2.0). Supported scope became Blender 4.5 LTS through 5.2.
- File-level `blender_support` / `blender_verified` frontmatter on rules and patterns, using two-part Blender versions.
- `SKILL.md` gained a `Modes` section with the strictly read-only Explain contract.

### Changed

- The NodeCue Blender add-on is retired and no longer referenced. Recommended path: this skill plus Blender's official Lab MCP server.
- Repository moved to the `nodecue` organization as `blender-node-skills`.
- `GeometryNodeList` is version-bounded instead of deleted; `Get List Item` and `List Length` were rewritten for generic list sockets.
- `Compare` and `Random Value` carry compatibility notes for the socket identifiers that changed in 5.2.
